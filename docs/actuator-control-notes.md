# 액추에이터(조광 필름) 제어 방식 — 검토 기록

부품 발주 전에 반드시 확인해야 하는 리스크. 지원금이 나오기 전까지는 이 문서를 기준으로 논의를 이어가고, 확정되는 대로 갱신한다.

## 진행 현황 (2026-09-29 기준)

- **필름 소싱처: TEAM PDLC로 확정.** 전압/주파수/소비전력/단계방식/필름 단품 구매 가능 여부/가격까지 필요한 정보를 전부 명확히 답변한 상태. 다른 두 곳(필름베이스코리아, PDLC코리아)은 이 정도 구체성의 답변을 아직 주지 않았고(또는 무응답), 4주차 제안서 게이트 일정상 더 기다릴 실익이 적어 이 업체로 단일화. "절대적으로 최선"이라기보다 "현시점에서 압도적으로 준비된 후보"라는 근거임 — 추후 더 나은 조건이 확인되면 재검토 가능.
- **파워서플라이/컨트롤러는 별개 이슈로 미확정.** yjsystems 및 추가 업체에 문의 발송 완료(2026-09-29), 답변 대기 중. 필름 확정이 방식 2 vs 방식 4 선택을 자동으로 정하는 게 아니므로 아래 "남은 결정 사항"은 그대로 유효함. **확인 필요**: yjsystems 외에 정확히 어느 업체(들)에 문의했는지 — 답변 오는 대로 여기에 업체명/조건 충족 여부 기록.
- **필름(TEAM PDLC) 문의도 사이즈 스펙(60cm×170cm) 포함해 발송 완료(2026-09-29), 답변 대기 중.**
- **필름 발주 사이즈: 가로 60cm × 세로 170cm(약 1.02㎡)를 작업 기준값으로 채택.** 원래 목표 사이즈 범위(가로 50~60cm × 세로 150~180cm, `hardware/bom.md` Tier2 참고)의 중간값으로 잡은 것이며, 실제 설치할 창문/블라인드의 정확한 실측값이 아직 문서화되어 있지 않음 — **확인 필요**. 실측값이 나오면 이 값과 TEAM PDLC 발주 사이즈를 함께 갱신할 것. TEAM PDLC에는 이 사이즈 기준으로 제작 가능 여부와 가로/세로 최대 제작 한도를 함께 문의.

## 배경

목표: PDLC(또는 전기변색) 조광 필름을 아두이노로 여러 단계(또는 연속)로 밝기 조절.

## 검토한 방식과 결론

### 1. 프리셋 버튼 컨트롤러 (상용 "4단계" 제품, 약 25만원대)
- 원리(추정): 트랜스포머에 전압이 다른 탭을 여러 개 두고 버튼/릴레이로 탭을 전환. 정현파 유지.
- 장점: 실제 판매 제품 확인됨, 회로 단순(릴레이로 버튼 시뮬레이션).
- 단점: 하드웨어에 고정된 단계 수(4개)만 가능. 정확한 단계별 투과율(%)은 스펙시트에 없어 판매자 문의 필요.

### 2. 0-10V 연속 디밍(또는 RS485 디지털 제어) + PDLC 전용 디머 파워서플라이
- 원리: PDLC 전용 파워서플라이가 0-10V 아날로그 제어 신호 또는 RS485 디지털 신호를 받아 내부적으로 안전하게 AC를 생성. 0-10V 방식이면 아두이노는 PWM→0-10V 변환 모듈을 거쳐 저전압 신호만 보냄(AC 쪽은 손대지 않음). RS485 방식이면 MAX485 같은 저가 TTL-RS485 변환 모듈로 아두이노와 직접 시리얼 통신 가능 — 부품이 저렴하고 국내에서 흔히 구할 수 있어 아두이노 인터페이스로는 오히려 이쪽이 더 다루기 쉬움.
- 실제 상용 제품 확인: [pdlcglass.com Dimmer Control Power Adapter](https://www.pdlcglass.com/products/dimmer-control-power-adapter/) — AC 0~60V, 50/100/200W, 벽스위치/리모컨/RS485/앱 제어 지원 (2026-09-28 재확인: 페이지 텍스트상 "0-10V" 단자가 명시적으로 언급되진 않고 "벽스위치·리모컨·RS485·앱"만 나열됨 — 실제 제어 인터페이스는 RS485/앱 쪽일 가능성이 높음, 0-10V 단자 유무는 판매자 직접 확인 필요).
- 대조 참고: 같은 제조사 라인업에 [Standard ON-OFF Mode Adapter](https://www.pdlcglass.com/products/standard-on-off-mode-adapter/)가 별도로 존재 — 이건 이름 그대로 완전 투명/완전 불투명 두 상태만 가능한 제품이고 Dimmer 제품과 확실히 구분됨. 국내 오픈마켓에서 파는 "디밍 파워서플라이"라는 이름이 붙은 저가 제품 중 상당수가 실제로는 이 "ON-OFF 모드"에 가까운 스펙(리모컨 설명이 전원 켜고 끄기 위주)인 경우가 있어 구매 전 반드시 대조 확인 필요 (아래 "검토 중인 구매 후보" 참고).
- 장점: 정현파 왜곡 문제 없음(파형 생성은 파워서플라이 내부 회로가 담당). 이론상 연속 제어 가능.
- 단점(확인 필요): 국내 소량구매·배송 가능 여부 미확인 (해외 B2B 사이트 기준 조사됨). 필름 자체의 전압-투과율 관계가 선형이라는 보장은 없음 — 실측 캘리브레이션 필요.

### 3. 트라이악(TRIAC) 위상제어 AC 디머 모듈 — 비권장으로 잠정 결론
- 원리: 아두이노가 AC 파형의 위상각을 직접 잘라서(phase-cut) 실효전압을 조절. RobotDyn류 모듈, 국내 다나와에서 2.7만원대부터 실구매 확인됨.
- **리스크**: 전자공학 포럼([edaboard.com 스레드](https://www.edaboard.com/threads/pdlc-smart-glass-power-supply.401025/)) 전문가 의견 — "TRIAC 기반 공급은 TRIAC를 ON/OFF 스위치로만 쓰지 않는 이상 정현파를 출력하지 않는다." PDLC/전기변색 소재는 파형 왜곡에 민감할 수 있어(깜빡임, 불완전한 반응) 백열등/LED용으로 설계된 이 부품이 PDLC엔 안 맞을 가능성이 있음.
- 포럼에서 제시한 대안: 오토트랜스포머(Variac, 수동/모터구동), 다단 변압기 탭 전환(방식 1과 동일 원리), 저항강하 회로(비효율적).
- **결론**: 이 방식은 채택하지 않는 걸로 잠정 결론. 소프트웨어로 세밀하게 제어하고 싶으면 방식 2(정식 0-10V 파워서플라이) 또는 방식 4(DIY 다단 변압기)로.

### 4. DIY 다단 변압기 조합 + 릴레이 (대안, 국내 부품으로 구현 가능)
- 원리: 서로 다른 전압을 내는 소형 트랜스포머 여러 개를 릴레이로 조합. 예: 트랜스포머 3개를 이진조합하면 2³=8단계 구현 가능.
- 장점: 정현파 유지, 국내에서 쉽게 구할 수 있는 부품만 사용, 소프트웨어(릴레이 ON/OFF 조합)로 단계 수 결정.
- 단점: 방식 1보다 회로/배선이 복잡함(직접 설계 필요).

## 남은 결정 사항

- [ ] 방식 2(0-10V 정식 파워서플라이) 국내 소싱 가능 여부 확인
- [ ] 방식 2 vs 방식 4 최종 선택
- [ ] 어느 방식이든: 저가 A4 PDLC 데모 필름으로 먼저 실물 반응 테스트 (부품 대량구매 전 리스크 검증)
- [ ] 전압(또는 탭/릴레이 조합)별 실측 투과율(BH1750) 캘리브레이션 → 룩업테이블 구성 → 정량지표(정확도) 근거로 사용

## 검토했다가 기각한 구매 후보 — 국내 쇼핑몰 "디밍 필름 전원 공급 장치 30-150W" (圣元电器/EEIO, 95,800원)

- 결론: **기각.** 상세페이지 이미지(안전 스위치 설명 "一键开关安全方便快捷节能，休眠状态时请关掉开关", 리모컨 아이콘 문구 "遥控开关电源")를 확인한 결과, 이 제품의 무선 리모컨은 단순 전원 On/Off 스위치 기능이고 밝기 단계 조절 기능이 없음. pdlcglass.com의 제품 라인업과 대조해보면 "Dimmer Control Power Adapter"가 아니라 "Standard ON-OFF Mode Adapter"류(완전 투명 ↔ 완전 불투명 두 상태만 가능)에 해당하는 것으로 판단됨.
- 우리 프로젝트는 "단계조광"(여러 단계 밝기 추종)이 핵심 요구사항이라 이 제품은 그대로 쓸 수 없음. 방식 1(프리셋 버튼)도 아니고 방식 2(0-10V/RS485 디머)도 아닌, 그보다 더 기본적인 On/Off 전용 제품.
- 와트/전압 참고(다른 후보 검토 시에도 적용되는 계산): 필름 면적이 중간 사이즈(약 0.75~1㎡)면 PDLC 소비전력(5~7W/㎡ 기준) 상 필요 전력은 4~7W 수준 → 30W(최소 옵션)로도 충분. 전압은 필름 정격 구동전압과 반드시 일치해야 함(필름 스펙시트 확인 필요).
- 액션 아이템: 오픈마켓에서 "디밍"이라는 이름만 보고 판단하지 말고, 상세페이지에 밝기 단계/연속조절/RS485/0-10V 언급이 실제로 있는지 확인. 없으면 On/Off 전용으로 간주. 대안으로 pdlcglass.com Dimmer Control Power Adapter(방식 2, RS485 제어 가능성 있음, 국내 배송·가격 미확인 — 이메일/WhatsApp 문의 필요) 또는 방식 4(DIY 다단 변압기+릴레이, 국내 부품만으로 구현 가능)를 우선 검토.

## 안전 주의사항

AC 220V가 지나가는 구간(파워서플라이 입력단, 트랜스포머/릴레이 배선)은 절연 하우징 처리 필수. 전시 시연 때 관람객 손이 닿지 않게 밀폐. 결과보고서에 안전 조치 명시.
