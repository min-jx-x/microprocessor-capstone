# 액추에이터(필름/파워서플라이) 확정 이후 로드맵

견적 문의(2026-09-28 발송) 답변 수신을 기준점으로 잡은 상세 실행 순서. 진행하면서 체크하고 갱신할 것.

## Phase 0. 견적 답변 도착 직후 — 구매 전 판단

- [ ] 국내 3곳(TEAM PDLC, 필름베이스코리아, PDLC코리아) + pdlcglass.com 답변을 표로 정리 (사이즈별 가격, 전압, 디밍 여부, 외부제어 인터페이스, 투과율, 반응속도, 배송기간, MOQ, AS)
- [ ] 필수조건 4가지(① PDLC 전용/정현파 ② 실제 디밍 기능 ③ 0-10V 또는 RS485 외부제어 단자 ④ 파워서플라이 출력전압=필름 정격전압) 충족 여부로 후보 스크리닝
- [ ] 분기 결정
  - (A) 국내 한 곳에서 필름+파워서플라이 세트로 조건 충족 → 그 업체로 단일 구매 확정 (제일 간단, 우선순위 1순위)
  - (B) 국내 필름은 조건 충족하는데 파워서플라이만 부족 → 필름은 국내에서, 파워서플라이는 pdlcglass.com(또는 다른 곳)에서 별도 구매 — 이 경우 전압 재확인 필수
  - (C) 어디서도 조건 충족 안 됨 → 방식 4(DIY 다단 변압기+릴레이)로 전환, `docs/actuator-control-notes.md` 방식4 기준으로 부품 재산정
- [ ] 4주차 제안서 심사 통과 여부 재확인 — 통과 전이면 결제는 보류하고 여기까지만 진행

## Phase 1. 1차 구매 (확정 즉시)

- [ ] A4(또는 유사 소형) 데모 필름 + 매칭 파워서플라이(가능하면 같은 세트) 발주
- [ ] 제어 방식이 확정됐다면 그에 맞는 추가 모듈도 동시에 발주
  - 0-10V 방식 → PWM-to-0-10V 변환 모듈
  - RS485 방식 → MAX485(TTL-RS485) 모듈
  - 방식 4(DIY) → 소형 트랜스포머 여러 개 + 릴레이 모듈(다채널)
- [ ] (병행, 언제 사도 무방) 공통 부품 발주: BH1750(GY-302), 아두이노 우노 R3, ESP8266 NodeMCU, 점퍼선/브레드보드 또는 만능기판, 절연 하우징 자재
- [ ] 팀원별 구매 담당/영수증 보관 — 지출 기록은 나중에 결과보고서 예산 항목에 필요

## Phase 2. 배송 대기 기간 — 상품 도착 전까지 할 일 (병행 작업)

필름/파워서플라이가 오기 전에도 진행 가능한 작업들. 이 기간을 놀리지 않는 게 일정(8주차 프로토타입 게이트) 관리의 핵심.

- [ ] `firmware/sketches/dimming_control_v1/dimming_control_v1.ino`의 TODO 순차 구현
  - BH1750 라이브러리 연동 (Wire.h + BH1750.h) — 센서만 있으면 바로 가능
  - 시간대 판단 로직 뼈대 (ESP8266 NTP 또는 RTC) 작성
  - `controlActuator()`를 확정된 제어 방식에 맞게 미리 구현 (필름 없이 시리얼 출력으로 로직만 먼저 검증 가능)
- [ ] BH1750 + 아두이노 + ESP8266 도착하는 대로 센서-MCU-Wi-Fi 통신 배선/테스트 먼저 진행 (필름 없이도 가능한 부분부터 진행해서 대기시간 최소화)
- [ ] 안전 하우징/절연 설계 확정 — AC 220V 구간 밀폐 방식 구체화, 케이스 자재 있으면 미리 준비
- [ ] `docs/quantitative-metrics.md`의 정확도/오탐률/지연시간 측정 절차를 실제 실험 프로토콜(측정 타이밍, 로깅 코드)로 구체화
- [ ] 팀 역할 분담 확정 및 `feature/기능명` 브랜치 생성 — 배선 담당, 소프트웨어 담당, 문서화 담당 나눠서 커밋 기록에 반영(개인 기여도 평가 대비)
- [ ] 결과보고서용 안전조치 문서 초안 작성
