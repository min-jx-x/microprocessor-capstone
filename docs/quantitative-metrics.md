# 정량지표 정의 (심사 체크포인트 ③)

제안서/결과보고서에 쓸 수치를 실측 기반으로 확정하기 위한 정의. 값 자체는 캘리브레이션 후 채워 넣는다.

## 정확도

목표 조도(lux) 대비 실제 도달 조도의 오차율(%). 예: 목표 200lux 설정 시 실측값이 180~220lux 범위 안에 들어오는 비율.
- 측정 방법: BH1750으로 각 제어 단계(또는 전압)별 실측 조도를 캘리브레이션 테이블로 구성 → 목표값 설정 후 실측값과 비교.

## 오탐률

의도치 않게 단계가 잘못 전환되는 비율 (센서 노이즈, 급격한 외부광 변화 등으로 오작동하는 경우).
- 측정 방법: 일정 시간(예: 30분) 동안 목표 조도 고정 상태에서 불필요한 단계 전환 발생 횟수 / 전체 판단 횟수.

## 지연시간

센서가 조도 변화를 감지한 시점부터 액추에이터(필름)가 반응을 완료하기까지 걸리는 시간(초).
- 측정 방법: 조도 급변 상황 재현 → 타임스탬프 로깅(센서 감지 시각, 제어신호 출력 시각, 필름 반응 완료 육안/센서 확인 시각).

## 전시 시연 시나리오 (30초 목표)

1. (0~5초) 초기 상태: 특정 단계로 필름 세팅된 상태에서 시작
2. (5~15초) 조도 변화 트리거(조명 변경 또는 시간대 모드 전환) → 센서 감지
3. (15~25초) MCU 판단 → 액추에이터 단계 전환
4. (25~30초) 목표 조도 도달 확인 (관람객이 눈으로 확인 가능하게)

캘리브레이션 데이터가 나오는 대로 이 문서에 실측 표를 추가한다.
