# 배선 (저전압 쪽, Arduino Uno)

| 부품 | 부품 핀 | Uno |
|---|---|---|
| BH1750 (GY-302) | VCC | 5V 또는 3.3V (모듈 사양 확인 필요) |
| BH1750 (GY-302) | GND | GND |
| BH1750 (GY-302) | SDA | A4 |
| BH1750 (GY-302) | SCL | A5 |
| BH1750 (GY-302) | ADDR | 미연결 (I2C 주소 0x23) |
| **대안 C(확정): 릴레이 4채널 — PDLC 컨트롤러 버튼 접점** | IN1 ~ IN4 | D4 ~ D7 (`actuator.h`의 `RELAY_PINS`) |
| 대안 A: PWM 출력 (미사용, 참고용) | 신호 | D9 (0-10V 변환 모듈 입력 또는 개발용 LED) |
| 대안 B: 릴레이 채널 (미사용, 참고용) | IN1 ~ IN4 | D4 ~ D7 (`actuator.h`의 `RELAY_PINS`) |

- **대안 C(확정)**: TEAM PDLC 디밍 컨트롤러의 개별 프리셋 버튼 4개 각각의 스위치 접점 양단에 릴레이 1채널씩(총 4채널) 병렬로 연결 — 릴레이가 닫히면 "버튼을 누른 것"과 전기적으로 동일해야 한다. 버튼 양단 전압/극성, 리모컨이면 배터리 전원 쪽인지(저전압) 확인 필요.
  - 릴레이 모듈 4채널 필요 — 지금 BOM은 1채널뿐이라 **3개 추가 발주 필요**(`hardware/bom.md` 참고)
  - 릴레이 모듈은 LOW에서 동작하는 제품이 많다. `RELAY_ACTIVE_LOW`를 모듈에 맞게 설정한다. (확인 필요)
  - 릴레이 코일 전압과 Uno의 5V 출력 신호 호환, 4채널 동시 구동 시 전원 용량은 구매한 모듈 사양서로 확인한다. (확인 필요)
  - 버튼을 누르고 있어야 하는 최소 시간(`BUTTON_PULSE_MS`)은 리모컨/패널 실측 후 조정
- 대안 A/B는 이번 컨트롤러엔 해당 없음 — DIY 다단변압기 등 다른 방식으로 바뀔 경우를 위해 코드만 남겨둠.

## 고전압 쪽 (필름 드라이버)

드라이버/변압기 모델이 정해지면 아래를 이 문서에 추가하고, `safety_checklist.md` 점검을 거친다.

- 드라이버(또는 변압기) 모델, 입력 전원, 출력 전압/용량, 필름 구동전압(60~110V)과의 호환
- 제어 입력 방식(0-10V 입력 / 탭 전환)과 아두이노 연결 방법
- 릴레이 접점의 교류 정격과 탭 전환 시 단락 방지(전부 끄고 대기 후 켜기) 확인
