# 부품 목록 (최종 구성, 3단계)

상용 디밍 컨트롤러 취소 후 확정한 구성입니다. 필름 업체가 구동 전압을 60~70V로 안내해, 필름 2장 × (꺼짐 / 약 45V)로 3단계를 직접 구동합니다. 6단계 모드(100V 추가)는 아래 참고에 정리했습니다.

## 제어부

| 부품 | 수량 | 용도 |
|---|:-:|---|
| Raspberry Pi 5 | 1 | 판단·제어·웹 서버 |
| microSD 카드 64GB (A2) | 1 | Pi OS와 코드 저장 |
| Pi 5 전원 어댑터 USB-C 5V 5A (27W) | 1 | Pi 전원 |
| BH1750 조도센서 (GY-302) | 1 | 실내 조도 측정, I2C |
| 5V 1채널 릴레이 모듈 | 4 (보유 7) | 필름마다 전원 릴레이 2개 (두 선 모두 차단) |
| 브레드보드 | 1 | 하이박스 2 안에서 5V·GND·신호 분배 |
| 점퍼선 (암-수, 암-암) | 적당량 | Pi ↔ 센서·릴레이 (암-수를 이어서 연장) |

## 필름 구동부 (교류)

| 부품 | 수량 | 용도 |
|---|:-:|---|
| PDLC 조광 필름 800×600 | 2 | 겹쳐서 투과율 3단계 |
| 한일 강압 변압기 300VA 220V → 100V | 2 | T1: T2에 전기 공급, T2: T1 출력을 다시 낮춰 약 45V |
| 무접지 탈피 전원선 5m (VCTF 2C × 1.5mm²) | 2 | 전원선 B(T2 → 하이박스 1), 남는 길이는 필름 리드선·짧은 연결선 |
| 220V → 110V 변환 플러그 (돼지코) | 2 | T2 입력, 전원선 B (4개 중) |
| 레버형 푸시 커넥터 3P | 2 (보유 10) | 전원선 B 두 가닥을 필름 A·B로 분기 |
| 방수 하이박스 150×200×130 | 2 | 1: 릴레이·교류 접속부, 2: Pi 5 (교류와 분리) |
| 누전차단기 있는 콘센트·멀티탭 | 1 | 변압기가 단권이라 필수 |

## 참고: 6단계 모드 (`LIGHTQ_LEVELS=6`)

- 릴레이 6개: 필름마다 전압 선택 2개(SA1·SA2, SB1·SB2) + 전원 1개(PA, PB)
- 전원선 A(T1 출력 100V)와 커넥터 4개 추가
- 100V는 필름 구동 전압(60~70V)을 넘으므로 60~70V 변압기나 슬라이닥스로 바꾸는 것을 권장

## 예비

- Arduino Uno, ESP8266 NodeMCU: 초기 프로토타입용, 현재 구성에서는 쓰지 않음

## 쓰지 않기로 한 것

- 상용 PDLC 디밍 컨트롤러: 납기 문제로 취소
- 트라이악 AC 디머: 위상 제어가 PDLC(용량성 부하)에 맞지 않음
- 100V 직접 구동: 필름 구동 전압 초과

배선은 [wiring_pi5.md](wiring_pi5.md), 안전 점검은 [safety_checklist.md](safety_checklist.md)를 따릅니다.
