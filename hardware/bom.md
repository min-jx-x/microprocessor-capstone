### 제어 방식별 추가 부품 (아래 중 방식 1개 선택 필요 — docs/actuator-control-notes.md 참고)

| 방식 | 추가로 필요한 부품 | 비고 |
|---|---|---|
| 방식 2-A: 0-10V 아날로그 디밍 | PWM-to-0-10V 변환 모듈 | 아두이노 PWM 출력을 0-10V로 변환, AC 쪽은 안 건드림 |
| 방식 2-B: RS485 디지털 제어 | MAX485(TTL-RS485 변환) 모듈 | 국내 소싱 쉬움, 아두이노와 시리얼 통신, 0-10V보다 다루기 쉬울 수 있음 |
| 방식 4: DIY 다단 변압기 + 릴레이 | 소형 트랜스포머 여러 개(예: 3개 → 2³=8단계) + 릴레이 모듈 여러 채널(예: 3채널 이상) | 수입/배송 불확실성 없음, 국내 부품만으로 구현 가능하나 배선 직접 설계 필요 |

**남은 결정**: 파워서플라이 방식(2-A / 2-B / 4) 확정 → 그에 맞는 추가 부품만 최종 BOM에 반영. 기존 Tier1/Tier2 표의 "릴레이 모듈 1채널"은 방식 4를 선택할 경우 채널 수를 늘려야 함.
