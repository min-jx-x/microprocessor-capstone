# 부품 목록 (최종 구성, 6단계)

상용 디밍 컨트롤러 취소 후 확정한 구성입니다. 필름 2장 × (꺼짐 / 약 45V / 100V)로 6단계를 직접 구동합니다.

## 제어부

| 부품 | 수량 | 용도 |
|---|:-:|---|
| Raspberry Pi 5 | 1 | 판단·제어·웹 서버 |
| microSD 카드 32GB (A2) | 1 | Pi OS와 코드 저장 (확인 필요: 보유 여부) |
| Pi 5 전원 어댑터 USB-C 5V 5A (27W) | 1 | Pi 전원 (확인 필요: 보유 여부) |
| BH1750 조도센서 (GY-302) | 1 | 실내 조도 측정, I2C |
| 5V 1채널 릴레이 모듈 | 6 | 필름마다 전압 선택 2개(두 선 동시 전환) + 전원 1개 |
| 점퍼선 (암-암) | 적당량 | Pi ↔ 센서·릴레이 |

## 필름 구동부 (교류)

| 부품 | 수량 | 용도 |
|---|:-:|---|
| PDLC 조광 필름 | 2 | 겹쳐서 투과율 6단계 |
| 한일 강압 변압기 300VA 220V → 100V | 2 | T1: 100V, T2: T1 출력을 다시 낮춰 약 45V |
| 전원케이블 16A 2C | 2 | 변압기 출력 → 릴레이 박스 |
| 220V → 110V 변환 플러그 (돼지코) | 2 | 변압기 출력 콘센트(11자형) 연결 |
| 레버형 푸시 커넥터 3P | 1 | 교류 배선 분기 |
| 방수 하이박스 150×200×130 | 1 | 릴레이와 교류 접속부 절연 케이스 |

## 시연 상자

| 부품 | 수량 | 용도 |
|---|:-:|---|
| 밝기조절 LED 집게형 스탠드 | 1 | 햇빛 역할 광원 |
| 폼보드 흰색 5T | 1 | 그림자를 보여 주는 스크린 |
| 우드락 검은색 5T | 1 | 벽과 천장, 외부 조명 차단 |

## 측정 도구

| 부품 | 수량 | 용도 |
|---|:-:|---|
| 멀티미터 (AC 전압 측정) | 1 | 필름 연결 전 T1·T2 출력 확인 (학교 보유 여부 확인 필요) |

## 예비

- Arduino Uno, ESP8266 NodeMCU: 초기 프로토타입용, 현재 구성에서는 쓰지 않음

## 쓰지 않기로 한 것

- 상용 PDLC 디밍 컨트롤러: 납기 문제로 취소
- 트라이악 AC 디머: 위상 제어가 PDLC(용량성 부하)에 맞지 않음

배선은 [wiring_pi5.md](wiring_pi5.md), 안전 점검은 [safety_checklist.md](safety_checklist.md)를 따릅니다.
