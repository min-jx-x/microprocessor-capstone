# 안전 점검표 (교류 고전압 연결 전 필수)

PDLC 필름은 수십~백 볼트대 교류로 구동한다. 감전과 화재 위험이 있으므로 아래를 모두 확인하기 전에는 교류 전원을 연결하지 않는다.

- [ ] 지도교수님 또는 전기 지식이 있는 분이 배선을 확인했다 (이름/날짜 기록)
- [ ] 완제품 드라이버/변압기를 사용한다 (직접 만든 승압 회로 사용 금지)
- [ ] 드라이버 출력 전압/용량이 필름 사양(구동전압 60~110V, 면적)과 맞는다 — 확인 필요
- [ ] 파형이 필름에 맞다 (README의 트라이악 위상제어 비권장 결론 준수) — 확인 필요
- [ ] 릴레이 접점의 교류 정격이 부하 전압/전류보다 충분히 크다 — 확인 필요
- [ ] 탭 전환 방식이면 여러 탭이 동시에 연결될 수 없다 (전부 끄고 대기 후 켜기, 가능하면 하드웨어 인터락)
- [ ] 퓨즈 또는 차단기가 입력 쪽에 있다
- [ ] 전선 접속부는 절연 처리(커넥터/수축튜브)되어 있고 노출된 도체가 없다
- [ ] 고전압 부분은 케이스 안에 있고 사용자가 손댈 수 없다
- [ ] 필름 단자부가 단락되지 않게 처리했다
- [ ] 배선을 바꿀 때는 반드시 전원을 뽑고 작업한다 (젖은 손/물기 주의)
- [ ] 처음에는 저전압 부하(LED, 소형 전구)로 동작을 시험했다

필름 취급 주의사항(물/세제 금지, 고온 금지 등)은 업체 견적서의 "제품특성 및 취급주의사항"을 따른다.
