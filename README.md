# microprocessor-capstone

순천향대학교 컴퓨터공학과 3학년 2학기 캡스톤디자인(마이크로프로세서) 팀 프로젝트 레포입니다.

## 팀 정보

| 항목 | 내용 |
|---|---|
| 과목 | 마이크로프로세서(캡스톤디자인) |
| 담당교수 | 양제파 |
| 팀명 | 라이트큐 |
| 팀원 | 강민재(팀장), 김대현, 곽재우 |

## 프로젝트 개요

- **문제 정의**: 아침에 잘 못 일어나는 대학생을 대상으로, 실내 조도를 시간대별(취침/기상/주간) 목표 광량 기준에 맞춰 자동으로 단계 조절하는 시스템.
- **4단계 구조**
  - ① 센서: BH1750(GY-302) 조도센서 — 실내 조도(lux) 측정
  - ② MCU: 아두이노 우노 R3(ATmega328P) — 센서값 판단, 액추에이터 제어신호 출력
  - ③ AI: 시간대별(취침/기상/주간) 목표조도 추종 판단 로직 (ESP8266으로 통신) — 구체 방식 미확정
  - ④ 액추에이터: PDLC/전기변색 조광 필름 + 전용 파워서플라이
- **기존 제품 대비 차별점**: 시판 전동커튼은 시간 예약·조도 임계값 개폐 수준이라 목표 조도를 단계적으로 추종하지 못하고 개인차도 반영 못 함 → 시간대별 목표 조도를 실시간 추종하고 사용자 기상 결과를 학습해 개인별 기준을 보정하는 단계조광 제어로 차별화.

## 액추에이터 제어 방식 — 미해결 기술 이슈 (중요)

부품 발주 전 반드시 확인해야 할 사항. `docs/actuator-control-notes.md` 참고.

- 트라이악(TRIAC) 위상제어 AC 디머 모듈은 저렴하고 아두이노 제어가 쉽지만, 위상제어 특성상 정현파가 아닌 파형을 출력함 — PDLC/전기변색 필름이 정현파를 요구할 경우 오작동 가능성 있어 **비권장**으로 잠정 결론.
- 대안 A: 0-10V 디밍 지원 PDLC 전용 파워서플라이 + PWM-to-0-10V 변환 모듈 (정식 방식이나 국내 소싱 확인 필요)
- 대안 B: 다단 변압기 탭 전환 + 릴레이 (정현파 유지, 국내 부품으로 구현 가능, 이미 찾은 "4단계 컨트롤러" 상용품이 이 원리로 추정됨)
- 어느 방식이든 "전압-투과율 실측 캘리브레이션(룩업테이블)"은 필수 — 이론적 선형 관계를 가정하지 않고 실측값을 정량지표 근거로 사용.

## 폴더 구조

```
.
├── firmware/       # 아두이노 우노(ATmega328P) 스케치 코드
│   └── sketches/
├── server/         # 백엔드 · AI 판단 로직 · 웹/앱 클라이언트
├── hardware/        # 회로도, 부품 리스트, 배선도
└── docs/           # 설계 문서, 발표자료 등 (회의록·진행상황은 노션에서 관리)
```

## 개발 환경

- 보드: 아두이노 우노 R3 (ATmega328P)
- IDE: Arduino IDE 2.x ([arduino.cc](https://www.arduino.cc/en/software)에서 설치)
- AI 레벨 1(클라우드 API) 기준: MCU는 센서·액추에이터 노드 역할, 판단 로직은 `server/`에서 처리

## 브랜치·커밋 규칙

과목 규정상 개인 기여도가 **동료평가·커밋 기록·시연 질의응답**으로 산정되므로, 커밋을 팀원별로 명확히 남기는 게 평가에 직접 영향을 줍니다.

- `main`: 항상 동작하는 상태 유지
- 기능 개발은 `feature/기능명` 브랜치에서 작업 후 PR로 병합
- 커밋 메시지는 `[파트] 내용` 형식 권장 (예: `[firmware] 초음파 센서 인터럽트 처리 추가`)
- AI 코딩 도구(Claude Code, Copilot 등) 사용은 허용되나, 시연에서 본인 코드를 직접 설명할 수 있어야 함
